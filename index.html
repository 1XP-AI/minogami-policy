개인정보처리방침 — Minogami

최종 수정일: 2026-11-15 · 적용 대상: Minogami Android 앱, Minogami iOS 앱

Minogami("이 앱")는 영어 원서를 읽는 것을 돕는 앱입니다. 책 페이지를 촬영하면 기기 안에서 글자를 읽어 내고, 읽기 수준에 맞는 어려운 단어·숙어·문법 포인트를 골라, 사진 위에 형광펜 표시와 짧은 뜻 메모로 보여 줍니다. 이 방침은 그 과정에서 여러분의 데이터에 무슨 일이 일어나는지 설명합니다.

요약하면: 저희는 서버를 운영하지 않고, 계정도 광고도 분석 도구도 없습니다. 사진은 기기를 떠나지 않습니다. 단어 뜻 분석을 위해 페이지에서 읽어 낸 텍스트만, 여러분이 고른 AI 제공자(Google Gemini API 또는 OpenAI API)에 여러분 자신의 API 키로 직접 전송됩니다.

만든 곳

이 앱은 1XP Inc.가 만들었습니다. 여러분의 콘텐츠를 받는 백엔드 서버를 운영하지 않으며, 회원가입·로그인 같은 계정 시스템이 없습니다.

기기에만 저장되는 것

다음은 여러분의 기기에만 저장되며, 저희에게 전송되지 않습니다.

  • API 키(Gemini, OpenAI) — Android에서는 Android Keystore가 관리하는 키로 암호화(AES-GCM)되어 앱 전용 저장소에, iOS에서는 키체인(Keychain)에 보관됩니다. 키는 해당 제공자의 API를 호출할 때만, 그 제공자에게만 전송됩니다.
  • 앱 설정 — 읽기 수준, 뜻을 적을 언어, 선택한 분석 제공자와 모델.
  • 진단 기록 — 페이지마다 처리 단계별 소요 시간과 실패 사유(예: 제공자가 응답하지 않은 이유)를 남기는 기록입니다. API 키는 기록하지 않습니다. 여러분이 설정에서 "Export Diagnostics(진단 내보내기)"를 눌러 직접 공유할 때만 기기 밖으로 나가며, 어디로 보낼지는 여러분이 고릅니다. 설정에서 언제든 지울 수 있습니다.

촬영하거나 고른 사진은 분석하는 동안 메모리에서만 쓰이고, 앱이 따로 파일로 저장하거나 어디로도 전송하지 않습니다. 앱을 삭제하면 위 데이터는 모두 함께 사라집니다.

기기 안에서만 처리되는 것

  • 글자 인식(OCR) — Android에서는 앱에 포함된 Google ML Kit 글자 인식 모델로, iOS에서는 Apple의 Vision 프레임워크로 기기 안에서 수행합니다. 사진은 이 과정에서 기기를 떠나지 않습니다.
  • 단어 난이도 판단 — 앱에 포함된 단어 학년 데이터로 기기 안에서 판단합니다.

AI 제공자(Gemini 또는 OpenAI)로 전송되는 것

단어 뜻·숙어·문법 설명을 만들기 위해, 이 앱은 설정에서 여러분이 고른 하나의 제공자에게만 다음을 전송합니다. 인증에는 여러분 자신의 API 키를 사용합니다. 이것은 여러분의 기기와 제공자 사이의 직접 연결(HTTPS로 암호화)이며, 저희 서버를 거치지 않고 저희는 그 내용을 받지 않습니다.

  • 페이지에서 읽어 낸 문장 텍스트와 그중 뜻을 알려 줄 후보 단어(각 단어가 나온 문장 포함)
  • 설정한 읽기 수준과 뜻을 적을 언어(요청 문구에 포함됨)

사진(이미지) 자체는 전송하지 않습니다. 이름·이메일·위치 같은 개인정보도 보내지 않습니다. 다만 촬영한 페이지에 적힌 글자는 그대로 전송되므로, 개인적인 메모나 민감한 내용이 적힌 페이지는 촬영하지 않는 것을 권합니다.

전송된 데이터는 각 제공자가 자신의 개인정보처리방침과 API 약관에 따라 처리하며, 이는 저희가 통제할 수 없습니다. 예를 들어 Gemini API의 무료 등급에서는 Google이 제출된 내용을 제품 개선에 사용할 수 있습니다. 자세한 내용은 각 제공자의 정책을 확인해 주세요.

  • Google Gemini API — 개인정보처리방침: https://policies.google.com/privacy · Gemini API 추가 약관: https://ai.google.dev/gemini-api/terms
  • OpenAI API — 개인정보처리방침: https://openai.com/policies/privacy-policy/ · API 데이터 처리: https://platform.openai.com/docs/guides/your-data

iOS에서만 있는 선택지 (Apple)

  • Apple 번역(기기 내) — Apple의 Translation 프레임워크로 단어 뜻을 기기 안에서 만듭니다. API 키가 필요 없고, 페이지 텍스트를 저희나 AI 제공자에게 보내지 않습니다. (언어 데이터를 처음 받을 때 iOS가 Apple에서 내려받을 수 있습니다.)
  • Apple Private Cloud Compute — 이 선택지를 고르면 페이지 텍스트와 후보 단어가 Apple의 Private Cloud Compute로 전송되어 처리됩니다. Apple은 이 데이터를 요청 처리에만 사용하고 보관하지 않으며 Apple도 열람할 수 없도록 설계했다고 밝히고 있습니다. 저희는 그 내용을 받지 않습니다. 참고: https://security.apple.com/blog/private-cloud-compute/ · Apple 개인정보 처리방침: https://www.apple.com/legal/privacy/

Google ML Kit의 진단 정보 (Android)

Android 앱에 포함된 Google ML Kit 글자 인식 라이브러리는 Google에 기능의 성능·사용 현황에 관한 진단 정보를 보낼 수 있습니다. Google의 설명에 따르면 여기에는 기기 정보(제조사·모델·OS 버전, ML 가속기), 앱 패키지 이름과 버전, 성능 지표·오류 코드·입출력 크기, 그리고 사용자나 기기를 고유하게 식별하기 위한 것이 아닌 설치별 식별자가 포함되며, HTTPS로 암호화되어 전송되고 다른 제3자에게 넘겨지지 않습니다. 사진이나 인식된 글자는 여기에 포함되지 않습니다. 자세한 내용: https://developers.google.com/ml-kit/android-data-disclosure

저희가 하지 않는 것

  • 사진·페이지 텍스트·API 키를 저희 쪽으로 수집·저장·전송하지 않습니다. 저희는 서버를 운영하지 않습니다.
  • 사용자 계정이 없습니다. 로그인도 회원가입도 없습니다.
  • 광고를 보여 주지 않으며 광고 SDK가 없습니다.
  • 저희가 넣은 분석(애널리틱스)·오류 보고 SDK가 없습니다. (위의 ML Kit 진단 정보는 예외로 설명했습니다.)
  • 광고 ID·위치·연락처를 읽지 않으며, 앱이나 웹사이트를 넘나들며 여러분을 추적하지 않습니다.
  • 앱 내 결제가 없습니다.

권한

  • 카메라 — 책 페이지를 촬영하기 위해서만 사용합니다. 거부해도 기존 사진을 골라 쓸 수 있습니다.
  • 사진 선택 — 기존 사진을 고를 때는 시스템 사진 선택기(Android Photo Picker, iOS PhotosPicker)를 사용하므로, 여러분이 고른 사진 한 장에만 접근하며 사진 보관함 전체에 접근하지 않습니다.
  • 인터넷 — 선택한 AI 제공자의 API를 호출하기 위해 사용합니다.

아동

이 앱은 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

데이터 삭제와 여러분의 선택

  • 설정에서 "Remove Key"로 저장된 API 키를 언제든 지울 수 있습니다.
  • 설정에서 "Clear Diagnostics"로 진단 기록을 지울 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터(API 키, 설정, 진단 기록)가 삭제됩니다.
  • 저희 서버에 보관되는 데이터가 없으므로 저희에게 삭제를 요청할 데이터가 없습니다. Gemini·OpenAI로 전송된 데이터는 각 제공자의 정책과 여러분의 해당 계정 설정에 따릅니다. 발급한 API 키는 Google AI Studio 또는 OpenAI 대시보드에서 폐기할 수 있습니다.

Privacy Policy — Minogami

Last updated: 2026-11-15 · Applies to: Minogami for Android and Minogami for iOS

Minogami ("the App") helps you read English books. You photograph a page; the App reads the text on your device, picks hard words, idioms and grammar points for your reading level, and shows short meanings as highlighter marks and notes on the photo.

The short version: we run no servers, and there are no accounts, ads or analytics. Photos never leave your device. Only the text read from the page is sent, directly, to the AI provider you choose (Google Gemini API or OpenAI API), using your own API key.

Who we are

The App is made by 1XP Inc. We operate no backend server that receives your content, and there is no account system.

What stays on your device

  • Your API keys (Gemini, OpenAI) — on Android encrypted with AES-GCM under an Android Keystore key in app-private storage; on iOS in the Keychain. A key is sent only to its own provider, when calling that provider's API.
  • Settings — reading level, definition language, selected provider and model.
  • Diagnostics log — timing and failure details per page (never the API key). It leaves the device only if you tap "Export Diagnostics" and choose where to share it. You can clear it in Settings.

Photos you take or pick are used in memory only while the page is analysed; the App does not save them to files or send them anywhere. Uninstalling the App removes everything above.

What is processed only on your device

  • Text recognition (OCR) — Google ML Kit's bundled model on Android, Apple's Vision framework on iOS.
  • Word difficulty — a word-grade dataset bundled with the App.

What is sent to the AI provider (Gemini or OpenAI)

To write meanings, idioms and grammar notes, the App sends the following to the one provider you selected, authenticated with your own API key, over a direct HTTPS connection that does not pass through us:

  • the sentences read from the page and the candidate words (with the sentence each appeared in);
  • your reading level and definition language (as part of the request text).

The photo itself is never sent, and no personal information such as name, e-mail or location is sent. Whatever text is printed on the page is sent as-is, so avoid photographing pages with private notes or sensitive content.

Each provider processes this data under its own privacy policy and API terms, which we do not control. For example, on the Gemini API's unpaid tier Google may use submitted content to improve its products.

  • Google Gemini API — https://policies.google.com/privacy · https://ai.google.dev/gemini-api/terms
  • OpenAI API — https://openai.com/policies/privacy-policy/ · https://platform.openai.com/docs/guides/your-data

iOS-only options (Apple)

  • Apple Translation (on device) — meanings are produced on the device by Apple's Translation framework; no API key, and page text is not sent to us or to an AI provider (iOS may download language data from Apple the first time).
  • Apple Private Cloud Compute — when selected, the page text and candidate words are sent to Apple's Private Cloud Compute for processing. Apple states this data is used only to fulfil the request, is not retained, and is not accessible to Apple. We never receive it. See https://security.apple.com/blog/private-cloud-compute/ and https://www.apple.com/legal/privacy/.

Google ML Kit diagnostics (Android)

The Google ML Kit text-recognition library bundled in the Android app may send Google diagnostics about the feature's performance and usage. According to Google this includes device information (manufacturer, model, OS version, ML accelerators), the app's package name and version, performance metrics, error codes and input/output sizes, and a per-installation identifier not intended to identify a user or device; it is encrypted in transit (HTTPS) and not transferred to other third parties. Photos and recognised text are not included. Details: https://developers.google.com/ml-kit/android-data-disclosure

What we do NOT do

  • We do not collect, store or receive your photos, page text or API keys. We run no servers.
  • There are no user accounts, no ads or ad SDKs, and no analytics or crash-reporting SDK added by us (ML Kit's own diagnostics are described above).
  • We do not read advertising IDs, location or contacts, and do not track you across apps or websites. There are no in-app purchases.

Permissions

  • Camera — only to photograph book pages. If you decline, you can still pick an existing photo.
  • Photo picking — through the system photo picker (Android Photo Picker, iOS PhotosPicker), so the App sees only the photo you pick, not your library.
  • Internet — to call the selected AI provider's API.

Children

The App is not directed to children under 13, and we do not knowingly collect personal information from children.

Deleting data and your choices

  • Remove a saved API key at any time in Settings ("Remove Key"); clear the diagnostics log with "Clear Diagnostics".
  • Uninstalling the App deletes everything stored on the device.
  • We hold no data on any server, so there is nothing for us to delete on request. Data sent to Gemini or OpenAI is governed by that provider's policies and your account settings there; you can revoke your API key in Google AI Studio or the OpenAI dashboard.
